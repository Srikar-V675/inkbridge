# Eval dataset format

```
eval/data/<set>/manifest.json          {"set": "synthetic-v1", "synthetic": true, "test_pages_only": true,
                                        "pages": ["p01-text", ...]}
eval/data/<set>/<page_id>/scene.json   {"elements": [...excalidraw elements...]}
eval/data/<set>/<page_id>/page.png     optional full-page export (needed only by the gemini reader)
eval/data/<set>/<page_id>/truth.json
```

`truth.json`:

```
{
  "page_id": "p01-text", "kind": "text|equation|diagram|mixed", "synthetic": true,
  "chunks": [                       # hand-boxed chunks (E5) with typed ground truth (E1)
    {"id": "c1", "box": {"x":0,"y":0,"width":100,"height":40},
     "kind": "handwriting|equation|diagram", "text": "...", "latex": null}
  ],
  "diagram": {"nodes": ["Start","Check"], "edges": [["Start","Check"]]},   # optional (E2/F1)
  "edits": [                        # optional scripted edits (E4)
    {"id": "e1", "type": "move", "chunk": "c1", "meaning_changed": false,
     "ops": [{"op":"translate","ids":["a","b"],"dx":200,"dy":0}],
     "text_after": "same words"}
  ]
}
```

Edit ops: `add {elements}`, `delete {ids}` (sets `isDeleted`), `translate {ids, dx, dy}`,
`redraw {ids, id_suffix}` (same geometry, new ids, originals deleted). `meaning_changed` is the
ground truth for "a real edit" (false for move, nudge, redraw identical); `text_after` is the
reading expected after the edit. Every page's `synthetic` flag must equal the manifest's.

`synthetic-v1` is SYNTHETIC: generated by `eval/make_synthetic.py`, not handwriting. It proves the
harness only.

`test_pages_only: true` is your own assertion that every page is a test page. Leave it false or absent for any page with personal content, and never commit real pages with personal content under `eval/data`.

## What the user must provide

1. 12-15 test pages (about 6-7 text and equations, 6-7 with diagrams), none from personal notes, drawn on the tablet in the Inkbridge canvas, one canvas per page.
2. For each page, `scene.json`: the Excalidraw elements (from `GET /documents/{id}/scene`, copy `elements`), pressure fields intact.
3. For each page, `page.png`: a full-page export from the browser (needed for the gemini reader and E1 image arms).
4. For each page, hand-typed `truth.json`: per hand-boxed chunk the `box` (canvas coordinates, from the chunk overlay or element bounds), `kind`, `text`, and `latex` for equations; for diagram pages the `diagram` node labels and directed edge list.
5. Hand-boxed chunks for E5: the boxes a human would draw (this is the same `chunks` list; do not copy the auto chunker's output).
6. A `manifest.json` with `"synthetic": false, "test_pages_only": true` (the gemini gate refuses without it) and the page list.
7. Scripted edits for E4 on a few text pages: `edits` entries for add, change word, erase, move, nudge, split, merge and redraw identical, each with `meaning_changed` and `text_after` (include meaning-preserving edits, or the test passes trivially).
8. Confirmation that `GEMINI_API_KEY` is set only in their shell, and that the INK-051/052 runs use `--allow-model` themselves.
