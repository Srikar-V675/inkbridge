# 0081: Chunker v2, line-aware clusters and connectors as links

INK-122. The v1 chunker has one distance for everything: a single `k` joins two lines of writing that belong apart, a long arc swallows a word through its bounding box, and pen arrows and their heads sit inside chunks, so moving an arrow changes a chunk's hash and its reading. v2 uses the stroke kinds (decision 0078, tech ref v4 section 4): writing clusters by line, connectors are links and are never chunk members.

Decision:
1. **v1 is untouched.** All v2 code is new modules (`chunker/lines.py`, `connectors.py`, `scene_v2.py`). The edits to v1 files are additive: new config fields with v1-neutral defaults, a `version == "v2"` early return in `chunk_scene`, optional `Chunking` fields, an optional `exclude` on `pin_groups`. A golden file (`server/tests/data/chunker_v1_golden.json`), committed before any source edit, proves v1 output is identical.
2. **Selection.** `ChunkerConfig.version` (`"v1"` default, `"v2"`). `ChunkerConfig.v2(**kw)` is `ChunkerConfig(version="v2", arrow_merge=1.0, link_reach=2.0, **kw)`; `arrow_merge` and `link_reach` are now measured in T (the stroke-kinds scale) instead of the page median. A save resolves: explicit `chunker_config` argument (tests) > `documents.chunker` (per canvas, `v1|v2|NULL`) > env `INKBRIDGE_CHUNKER` > `v1`. An invalid env value warns on stderr and means `v1`. Read at call time.
3. **Switching re-chunks at once** (`db.set_chunker`, same `BEGIN IMMEDIATE` as a save, one transaction). Orphan collection is not run there; the next save collects. `documents.updated_at` is not touched.
4. **Per-canvas setting** is `PATCH /documents/{id} {"chunker": "v1"|"v2"|"default"}` (`default` clears the override). `DocumentOut.chunker` is the effective value. No WebSocket broadcast: the web refetches chunks on save, push, reconnect and wake, and a switch is an operator action.
5. **T** is `analyse(elements).scale` when above 0, else the median element extent as in v1, floored at `min_median`. The local-scale re-cluster (`own < 0.5 * T`) and the `max_extent` cap (INK-081) are kept.
6. **Line-aware join.** Same line (vertical overlap at least half the smaller height): join when the horizontal gap is under `k * T`. Next line: join only when the boxes overlap in x and the vertical gap is under `next_line * T` (0.5). A stroke over `long_stroke * T` (2) joins by its ink (samples every T/2, at most 256 per stroke), not its box. Underline joins writing within `max(next_line, 0.75) * T`. A scribble joins what its box overlaps. A container explicitly unions every element whose box centre is inside its polygon. Grid cell is `k * T`; a cell already holding one group is skipped.
7. **Connector membership.** Connector and head strokes, native arrows and lines and their bound labels are never members of a v2 chunk (so never in a hash, box or crop). Pins drop them too. A connector's heads and bound labels travel with it.
8. **Connector outcome** (each end maps to the nearest chunk box within `link_reach * T`; a bound native end uses its bound element's chunk): both ends found in different chunks and path at most `arrow_merge * T` (a tick) merges them when neither is pinned or agent, the tick itself staying out of every chunk; otherwise a link row; both ends in one chunk makes nothing; a free end on either side makes the connector its own chunk (connector, heads, labels) with `kind='connector'` and no link. A connector with under 2 points is ignored. A freedraw connector with a head points at the end nearer the head; otherwise drawn order.
9. **`links` rebuilt** (migration 0009, one-way): adds `source` (`stroke|agent|user`), `label`, `confidence`, `element_id` (empty string when none, so it sits in the primary key), and kinds `arrow|near|answer|relates|derived`. Two arrows between the same pair are two rows. On a save only `source='stroke'` rows are deleted and rebuilt; other sources are untouched and go only when a chunk is orphaned and collected. Nothing writes non-stroke rows yet, and nothing re-points them at successors. Readers that returned `{to, kind}` now `SELECT DISTINCT`, so the API and `get_subgraph` shapes are unchanged. `documents.chunker` is added by the same migration.
10. **Confidence** (0..1, two decimals): `0.4 + 0.3 * evidenced + 0.3 * (1 - worst_end_distance / reach)`, where `evidenced` is a head found (pen), an arrowhead on a native arrow, or both ends bound.
11. **Id continuity.** The matcher ignores connector ids (native and, for v2, stroke connectors), so v1 chunks that held pen arrows compare on their writing. Chunks that really change are orphaned with `successor_of`; `check_sync` reports both a split and a merge as `replaced` (it has no `merged` key and none is added).
12. **Connector chunks are never sent to the recognizer**: `recognition_candidates` and `sync.needs_reading` skip `kind = 'connector'`, so Gemini never overwrites the kind. The export skill reads chunks from `read_canvas`; skipping `connector` chunks there is for the arrow-to-nothing detector ticket.
13. **Hashes are unchanged** (`canvas/hashes.py` is not edited). A chunk's members change once on switching, so its hash and reading change once: one round of re-reads is expected.
14. **Migration 0009 is one-way.** Back up first: `sqlite3 data/inkbridge.db ".backup data/inkbridge.pre-0009.db"` (or copy the file) with the API stopped.

Rollout: `cp data/inkbridge.db data/inkbridge.copy.db`, run the API on the copy with `INKBRIDGE_CHUNKER=v2` (or `PATCH /documents/{id} {"chunker":"v2"}`), `check_sync` a note exported from real pages, expect `replaced` for split or merged chunks and `fresh` for untouched ones, after one round of re-reads. Threshold tuning on 12 to 15 real pages against hand counts is E5, not this ticket: `k`, `next_line`, `long_stroke`, `link_reach` and `arrow_merge` are start values.

Known limits: a long cursive stroke classified `connector` leaves the chunks; a pen arrow whose head is drawn first or more than two strokes later (decision 0078) leaves a stray head as `writing` inside a chunk, so the hash changes if it moves; a page of only native text has no T from strokes and falls back to the median extent; mixed pages with few strokes get a noisy T.
